# Changelog

## 0.3.1
- Fixed the dialog constructor to accept the QGIS interface object passed by the plugin launcher.
- Retained support for loaded QGIS project vector layers, File Geodatabases, and Shapefiles.

## 0.3.0
- Added support for extracting geometries from vector layers loaded in the current QGIS project.
- Added a refresh action for the loaded QGIS layer list.
- Retained direct File Geodatabase and Shapefile input.
- Updated plugin metadata and publication documentation.

## 0.2.0
- Initial public development version with File Geodatabase and Shapefile input.
- WKT and WKB hexadecimal extraction, preview, clipboard copy, and CSV export.
